# Portafolio personal

Portafolio web de **Anyi Daniela Colorado Serna**, desarrolladora de software.
Hecho como práctica de React, con diseño pensado primero para el celular.

## Tecnologías

- React
- Vite
- React Router
- CSS

## Pantallas

- **Inicio:** presentación personal.
- **Proyectos:** AgroHospeda (Java) y Crochet con Amor (Angular, Java y Spring Boot).
- **Contacto:** correo y GitHub.

## Cómo ejecutarlo

```bash
npm install
npm run dev
```

Luego abre la dirección que aparece en la terminal (normalmente `http://localhost:5173/`).
